# Escalera

- **Qué es:** promoción gradual de una observación hacia el escalón mínimo que
  puede resolverla con seguridad y evidencia.
- **Cuándo:** desde el diagnóstico y cada vez que el alcance, riesgo,
  colisiones o deuda superan al escalón actual.
- **Cómo:** avanzar `OBSERVATION → DIAGNOSIS → cambio elegido → QUALITY/CRISOL
  cuando aplique → CLOSURE`; acumular microfixes visibles y promoverlos cuando
  ya no sean una unidad pequeña.
- **No es:** ejecutar siempre todas las fases, degradar un hotfix a microfix
  para evadir gates ni refactorizar antes de comprobar una hipótesis rápida.
- **Ejemplo:** un microfix confirma una utilidad; tres microfixes sobre el mismo
  contrato se promueven a Crisol para factorizar y cerrar la solución.
