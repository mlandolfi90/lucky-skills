# Autopsia

- **Qué es:** análisis postejecución de una falla ya corregida, estabilizada o
  revertida.
- **Cuándo:** tras un rollback, fallo repetido o cierre condicionado por una
  incidencia.
- **Cómo:** reconstruir hechos, causa raíz, brecha de detección, corrección,
  recuperación y prevención mínima; preferir un subagente independiente.
- **No es:** el primer paso de recuperación, una búsqueda de culpables ni
  autorización para ampliar el TARGET.
- **Ejemplo:** después de restaurar una adopción fallida, registrar qué
  validación faltó y el gate mínimo que evita repetirla.
