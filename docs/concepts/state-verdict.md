# Veredicto de estado

- **Qué es:** síntesis descriptiva de las cuatro fuentes.
- **Cuándo:** al cerrar una ejecución de Sextante.
- **Cómo:** usar `ALIGNED`, `DRIFT`, `PARTIAL` o `STALE`.
- **No es:** un gate ni una autorización humana.
- **Ejemplo:** `STATE_VERDICT=DRIFT` si remoto y runtime prueban versiones distintas.
