# Decisión humana

- **Qué es:** intervención requerida para continuar una sola dependencia.
- **Cuándo:** cuando Sextante no puede resolver un bloqueo sin autoridad humana.
- **Cómo:** usar `CONFIRM_TARGET`, `CHOOSE_SOURCE`, `PROVIDE_ACCESS`,
  `CONFIRM_SOURCE_ACCESS`, `ACCEPT_RISK` o `STOP`; aceptar lenguaje natural
  salvo riesgo.
- **No es:** una lista de preguntas simultáneas ni autorización encadenada.
- **Ejemplo:** dos runtimes candidatos producen `CHOOSE_SOURCE`.
