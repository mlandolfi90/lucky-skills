# Scope de inspección

- **Qué es:** fuente o conjunto de fuentes autorizadas para una consulta.
- **Cuándo:** cuando existen varios remotos o runtimes candidatos.
- **Cómo:** pedir al humano cuál consultar y limitar la sonda a esa selección.
- **No es:** TARGET ni permiso para escribir en lo inspeccionado.
- **Ejemplo:** inspeccionar `runtime:dev` no autoriza un deploy.
