# Nivel de ejecución

- **Qué es:** profundidad efectiva con la que un harness ejecutó Sextante.
- **Cuándo:** en cada comprobante.
- **Cómo:** usar `NATIVE`, `ADAPTED`, `DEGRADED` o `MANUAL`.
- **No es:** madurez de la skill ni veredicto del proyecto.
- **Ejemplo:** evidencia aportada sin runtime ejecutable puede ser `MANUAL`.
