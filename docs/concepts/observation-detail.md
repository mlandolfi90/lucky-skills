# Detalle de observación

- **Qué es:** razón precisa detrás del resultado resumido de una fuente.
- **Cuándo:** cuando el comprobante necesita explicar ausencia o fallo.
- **Cómo:** usar hechos como `NO_COMMIT`, `NO_REMOTE`, `UNKNOWN`,
  `UNREACHABLE`, `TIMEOUT` o `NOT_APPLICABLE`.
- **No es:** un reemplazo de `STATE_VERDICT` ni un permiso operativo.
- **Ejemplo:** `REMOTE=PARTIAL` con `REMOTE_STATE=TIMEOUT`.
