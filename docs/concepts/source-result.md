# Resultado de fuente

- **Qué es:** estado normalizado de local, remoto, runtime o capacidades.
- **Cuándo:** después de intentar comprobar una fuente.
- **Cómo:** usar `ALIGNED`, `DRIFT`, `PARTIAL`, `STALE` o `NOT_APPLICABLE`.
- **No es:** permiso para ejecutar una acción.
- **Ejemplo:** `RUNTIME=PARTIAL` cuando existe una pista pero falta acceso.
