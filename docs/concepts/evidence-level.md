# Nivel de evidencia

- **Qué es:** procedencia y fuerza de un valor observado.
- **Cuándo:** para cada fuente no trivial o aportada manualmente.
- **Cómo:** usar `VERIFIED_DIRECT`, `HUMAN_PROVIDED`, `DECLARED` o `UNKNOWN`.
  Las dos primeras pueden sostener alineación; las dos últimas solo orientan y
  permanecen parciales.
- **No es:** un veredicto de estado.
- **Ejemplo:** salida pegada por el dueño es `HUMAN_PROVIDED`.
